# Демо для клиентов

Публичный репозиторий с GitHub Pages: страницы, которые показываем клиентам по ссылке, – карты структуры, макеты,
интерактивные отчёты. Ссылка на материал: `https://vitamin1zer.github.io/demo/<проект>/<страница>/`.

## Правила

- Репозиторий открыт всем: никаких доступов, паролей, токенов, выгрузок с личными данными, внутренних цен и переписки.
  Публикуем только то, что и так уходит клиенту.
- Все страницы закрыты от индексации (`noindex, nofollow`): копии клиентских страниц в поиске – это дубли.
- Корневая страница не перечисляет проекты; ссылку на материал присылаем клиенту отдельно.
- Шрифты и картинки внутри страниц становятся общедоступными – коммерческие шрифты без веб-лицензии не публикуем.
- Убрать материал – удалить его папку, закоммитить и отправить; ссылка начнёт отдавать страницу 404.

## Как опубликовать

```
python publish.py <HTML-файл или папка с index.html> <проект> <страница>
```

Например: `python publish.py ../victory/u-zubnogo/work/карта-структуры u-zubnogo karta-struktury`.
Скрипт берёт страницу и только те файлы, на которые она ссылается, оборачивает фрагмент в документ, ставит `noindex`,
проверяет файлы на доступы, кладёт всё в `<проект>/<страница>/`, коммитит и отправляет. Повтор той же команды обновляет
материал по той же ссылке. `--out ПАПКА` – собрать без публикации, чтобы проверить.
